# signup-form バックエンド セットアップ手順

LPの「βテスターに無料登録する」フォームの送信先です。Google Apps Script + Googleスプレッドシートで構成されており、追加費用・新規アカウント作成なしで動きます。所要時間の目安は3〜5分です。

## 手順

1. Googleスプレッドシートを新規作成する（[sheets.new](https://sheets.new)）。
2. 1行目にヘッダーを入力する：`日時 / 会社名 / お名前 / メールアドレス / 関心のある分野`
3. メニューから「拡張機能」→「Apps Script」を開く。
4. デフォルトで開いている `コード.gs` の中身を全て削除し、このディレクトリの `Code.gs` の内容を貼り付ける。
5. 3行目付近の `NOTIFY_EMAIL` が通知を受け取りたいメールアドレスになっているか確認する（現在は `takenori.kouda@gmail.com` を設定済み）。
6. 右上の「デプロイ」→「新しいデプロイ」をクリック。
7. 「種類の選択」の歯車アイコンから「ウェブアプリ」を選択。
8. 「実行するユーザー」は自分（自分のGoogleアカウント）、「アクセスできるユーザー」は**全員**を選択する（LPからの送信を匿名で受け付けるために必要。個人情報が外部から閲覧できるようになるわけではなく、送信を受け付けられるようになるだけ）。
9. 「デプロイ」をクリックすると、初回のみ権限の承認を求められる（自分のGoogleアカウントでの操作）。承認後、**ウェブアプリのURL**が発行される。
10. 発行されたURLを、Claude（このプロジェクトを担当しているセッション）に伝える。`website/js/main.js` の該当箇所にそのURLを反映する。

## 動作確認

デプロイ後、LPの `#signup` フォームからテスト送信し、スプレッドシートに1行追加されること・通知メールが届くことを確認してください。

## 送信内容を更新した場合

`website/index.html` の `#signupForm` にフィールドを追加・変更した場合は、`Code.gs` の `doPost` 内でそのフィールドを読み取る処理も対応して追加する必要があります（現状は `company`/`name`/`email`/`interest` の4項目のみ）。
