# 01_lp.md — サービスLP（AOR一般紹介ページ）

対応する設計書: [01_concept.md](../strategy_v2/01_concept.md) / [09_pricing.md](../strategy_v2/09_pricing.md) / [10_lp_structure.md](../strategy_v2/10_lp_structure.md) / [14_risk.md](../strategy_v2/14_risk.md)

## 位置づけ

このLPは「特定企業向けにパーソナライズされたレポート画面」（[02_report_preview.md](02_report_preview.md)）とは別物。
AOR というサービスそのものを説明する**一般公開ページ**であり、以下のような流入者を想定する。

- パーソナライズレポートを受け取り、「これは何のサービスか」「送信元は何者か」を確認しに来た担当者（不安の解消）
- 紹介・検索経由でサービスを知った見込み顧客
- 将来のOEM/代理店候補（[09_pricing.md](../strategy_v2/09_pricing.md)の(B)顧客）

## 目的

「勝手に分析されて送りつけられた」という不信感を持たれた場合でも、このページに来れば
運営者・仕組み・料金・データの扱いが透明に分かる状態を作ること。ブランド毀損リスクへの
構造的な対策の一つ（[14_risk.md](../strategy_v2/14_risk.md)）でもある。

## 誰が使うか

1. レポート受信者（送信元確認目的）
2. 見込み顧客（自発的な検討目的）
3. 将来の代理店・OEM候補

## ユーザー心理

警戒（なぜ自社の情報を分析されたのか）→ 納得（公開情報のみ・人間レビューありと知り安心）→
興味（自分の会社でも試してみたい / 導入したい）という順で心理が変化する前提で構成する。

## CTA

- 一次CTA: 「サービスについて相談する」（お問い合わせ・資料請求フォームへの遷移。
  **その場での即時レポート生成は行わない**。送信された問い合わせは、他の全ての生成物と同じく
  人間が内容を確認した上で個別に対応する）
- 二次CTA: 「料金を見る」

### セルフサーブ即時生成フォームを採用しない理由

初期検討では「会社ドメインを入力すると即座にレポートを生成する」自己申告フォームが
候補にあったが、**Human in the Loop原則（[06_human_review.md](../strategy_v2/06_human_review.md)の
「適用範囲の原則」）と両立しない**ため採用しない。即時性を担保しようとすると人間レビューを
経ずに配信することになるか、レビュー待ちにすると結局「即時」ではなくなるかのいずれかになる。
この判断の経緯は [CHANGELOG.md](CHANGELOG.md) を参照。

## 画面構成

1. **ヘッダー**: サービスロゴ、ナビ（サービス概要・料金・FAQ・お問い合わせ）
2. **ヒーロー**
   - キャッチコピー: 「価値を先に見せる、営業のかたち。」（[01_concept.md](../strategy_v2/01_concept.md)のコンセプトを直訳）
   - サブコピー: 「プロフィール入力は不要です。会社名を入れるだけで、御社向けのレポートが届きます。」
   - 一次CTAボタン
3. **課題提起セクション**: 「なぜ届いたのか」を先回りして説明する短い一文
   （例: 「一般的な営業メールとは違い、このレポートは貴社の公開情報だけを元にAIが作成し、
   必ず人間が内容を確認してからお送りしています」）
4. **仕組み説明（3〜4ステップ）**
   - 会社の公開情報を解析 → 関連する市場変化を抽出 → 人間が確認 → レポートをお届け
   - [05_ai_pipeline.md](../strategy_v2/05_ai_pipeline.md)・[06_human_review.md](../strategy_v2/06_human_review.md)を
     一般向けに平易に要約した表現にする
5. **実際のレポート例**
   - 匿名化されたサンプル企業（例:「製造業A社」）に対するレポートの抜粋を画像/引用ブロックで掲載
   - [02_report_preview.md](02_report_preview.md)の縮小版に相当
6. **料金セクション**
   - Free / Standard / Pro の3プランを比較表で提示（[09_pricing.md](../strategy_v2/09_pricing.md)準拠）
   - 「まずは無料レポートから」という導線を強調し、価格ページ単体でのコンバージョンは狙わない
7. **FAQ**
   - 「なぜ自社の情報を分析したのか」（公開情報のみ使用、個人情報は扱わない旨を明記）
   - 「この情報はどこから来ているのか」（[04_company_analysis.md](../strategy_v2/04_company_analysis.md)の
     データソースを一般向けに要約）
   - 「配信停止したい」（オプトアウト導線への直接リンク）
   - 「料金はいつから発生するか」
   - 「AIが自動生成しているのか」（Human in the Loopである旨を明記、[06_human_review.md](../strategy_v2/06_human_review.md)）
8. **フッター**: 運営会社情報、プライバシーポリシー、特定商取引法に基づく表記（有料化後）、
   オプトアウト導線

## 表示項目まとめ

| 項目 | 内容 |
|---|---|
| ヒーロー | キャッチコピー、サブコピー、CTA |
| 仕組み説明 | 3〜4ステップの図解（テキストベース） |
| レポート例 | 匿名化サンプル1件の抜粋 |
| 料金表 | Free/Standard/Pro比較 |
| FAQ | 5項目程度 |

## 必要データ

- 静的コンテンツ（コピー、料金、FAQ文言）のみで構成可能
- レポート例は実データではなく、匿名化したダミー企業のサンプル

## 今はダミーで良い部分

  [09_pricing.md](../strategy_v2/09_pricing.md)）
