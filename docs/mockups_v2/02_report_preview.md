# 02_report_preview.md — 無料レポート画面

対応する設計書: [02_user_journey.md](../strategy_v2/02_user_journey.md) / [05_ai_pipeline.md](../strategy_v2/05_ai_pipeline.md) / [07_free_report.md](../strategy_v2/07_free_report.md) / [10_lp_structure.md](../strategy_v2/10_lp_structure.md) / [04_company_analysis.md](../strategy_v2/04_company_analysis.md)

## 位置づけ

営業メール1通目のリンク先。エンドターゲット企業の担当者が最初に到達する画面であり、
**このサービス全体で最も重要な画面**（[16_validation_plan.md](../strategy_v2/16_validation_plan.md)の仮説1・2に直結）。

## 目的

読んだ瞬間に「これは自分（自社）向けだ」と感じてもらい、「さらに詳しく見たい」という
欲求を自然に生み出すこと。この画面単体が事実上の営業活動そのものである。

## 誰が使うか

メール内リンクをクリックした、エンドターゲット企業の担当者・経営者（初対面、警戒心を持った状態で来訪する）。

## ユーザー心理

1. 到達直後（0〜3秒）: 「なんだこれ」という警戒
2. 会社名・業種が正しく表示されているのを見て: 驚き・興味
3. why_now（なぜ今か）・why_company（なぜこの会社か）を読んで: 「これは自分（自社）のために
   考えられた分析だ」という納得（**件数ではなく深さ**による信頼構築）
4. 最初のアクション案・さらに検討可能なテーマ（ロック）を見て: 「もっと具体的に知りたい」という欲求

## CTA

- 一次CTA（サマリー直後）: 「さらに詳しいレポートを見る」→ [03_email_capture.md](03_email_capture.md)へ
- 二次CTA（ページ末尾）: 同上（[10_lp_structure.md](../strategy_v2/10_lp_structure.md)のCTA二箇所配置方針）
- 訴求文言はCTAボタンの直近に配置し、「登録すると、このOpportunityの市場規模・競合状況・
  リスクまで踏み込んだ追加分析が見られます」という具体的なベネフィットを明示する
  （抽象的な「もっと見る」にしない。**新しいOpportunityが開放される、という訴求はしない**
  ── 実際には同じOpportunityの理解を深める体験であるため、[07_free_report.md](../strategy_v2/07_free_report.md)
  「登録直後の体験（追加分析）」と表現を一致させる）

## 画面構成・表示項目（改訂: 1件深掘り方式）

**設計変更**: 従来案は「関連度の高い市場変化を最大3件、カード形式で並べる」構成だったが、
実際の経営者・事業責任者に「自社向けに考えられた分析だ」と感じてもらうため、**最も関連性の高い
Opportunity1件に絞り込み、深く掘り下げて見せる**構成へ改訂する
（[07_free_report.md](../strategy_v2/07_free_report.md)「構成案（改訂: 1件深掘り方式）」に対応）。

1. **ヘッダー帯（統合）**
   - 「〇〇株式会社 様 向けレポート」（会社名を明記、パーソナライズの一次証明）
   - レポート生成日
   - 業種・事業内容の要約（1行、AI推定である旨のラベル付き）
   - **「このレポートは送信前に人間が内容を確認しています」の一文**（バッジまたはアイコン付きで明示。
     [06_human_review.md](../strategy_v2/06_human_review.md)の原則を受信者が確認できる形にする）
   - 推定に誤りがある場合の訂正導線（「情報が異なる場合はこちら」→問い合わせ、目立つ位置に配置）
2. **参照元の開示**
   - 「貴社の会社概要ページ・採用ページ」に加え、「官公庁資料」「業界団体レポート」「ニュース」等、
     参照した情報源の**種別（source_type）**が分かる形で一覧表示する
     （[04_company_analysis.md](../strategy_v2/04_company_analysis.md)の「参照元の開示」、ミラー効果＋
     一次情報・業界情報による裏付けの両方を示す）
3. **深掘りOpportunity（1件）**
   - タイトル、関連度バッジ（高）
   - **なぜ今この機会なのか（why_now）**: 市場・制度側のタイミングの説明
   - **なぜこの会社なのか（why_company）**: 対象企業固有の事実との結びつき
   - **根拠となる市場変化（market_change）**: 変化そのものの説明
   - **参照情報（evidence）**: 引用抜粋＋出典を、情報源の種別（一次情報／業界情報／ニュース）が
     分かる形でその場に表示する（外部リンクへの遷移だけに頼らない。リンクは抜粋の下に補足として置く。
     複数の情報源を組み合わせて提示することで「ニュースの後追い」ではないことを示す）
   - **最初のアクション案（first_action）**: 完全に具体的な実行アクションを見せきる
     （[07_free_report.md](../strategy_v2/07_free_report.md)の「有料版へのブリッジ設計」）
4. **さらに検討可能なテーマ（ロック）**
   - 深掘りには至っていない追加テーマについて、**タイトルのみ**をロック表示する
     （例:「🔒 新規収益モデル候補」「🔒 パートナー戦略候補」）
   - 根拠・アクションは一切持たせない（生成すらしていない状態であることが前提。詳細は有料版で
     初めて分析される）
5. **CTA（一次）**: 「さらに詳しいレポートを見る」＋追加分析が見られる具体的ベネフィット文言
6. **フッター**
   - 送信元（運営会社）情報
   - 「このレポートについて詳しく知る」→[01_lp.md](01_lp.md)へのリンク
   - 配信停止（オプトアウト）導線
7. **CTA（二次）**: 一次CTAと同一

**削除した要素**: 「社会的証明（任意）」セクションは、実績が乏しい段階でのプレースホルダー表示が
かえって信頼性を損なうため、MVPでは掲載しない（実績が蓄積された段階で再検討）。

## Opportunity Scoreの扱い

「総合スコア0〜100のゲージ表示」は、算出根拠が伴わない数値がかえって懐疑心を招くため採用しない。
[05_ai_pipeline.md](../strategy_v2/05_ai_pipeline.md)の内部信頼度スコアは
社内のレビュー優先度判定（[05_admin_review.md](05_admin_review.md)）にのみ使用し、
受信者向けの表示には使わない。受信者向けにはOpportunityの**関連度バッジ（高）**のみを表示する。

## 計測（Phase1で必須）

以下のイベントを計測する。詳細な仕様は[07_measurement.md](07_measurement.md)を参照。

- ページ到達（メール経由か、直接アクセスか）
- スクロール到達率（各セクションまで到達したか、特にwhy_now/why_companyまで読まれたか）
- 「さらに検討可能なテーマ」セクションの表示有無
- CTAクリック（一次/二次どちらか）

## 必要データ

- [05_ai_pipeline.md](../strategy_v2/05_ai_pipeline.md)の①〜⑥の出力。特に⑤⑥で生成される
  `free_opportunity`（title, why_now, why_company, market_change, evidence, first_action）
- `locked_opportunities`（タイトルのみの配列。「さらに検討可能なテーマ」用）
- 参照元情報（`source_pages`、source_type/source_roleを含む）
- [06_human_review.md](../strategy_v2/06_human_review.md)のレビューを通過した承認済みコンテンツのみを表示する
  （未承認のドラフトがこの画面に出ることは設計上あってはならない）

## 今はダミーで良い部分

- 関連度バッジの自動判定ロジック（Phase1ではレビュー担当者が最終決定してよい。表示UIだけ先に固める）
- 多言語対応
