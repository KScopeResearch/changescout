# 11_sales_process.md — 営業フロー

## 全体フロー

```
ターゲットリスト作成
   ↓
AIパイプライン実行（05_ai_pipeline.md）
   ↓
人間レビュー・承認（06_human_review.md）
   ↓
送信
   ↓
開封・クリック・登録のモニタリング
   ↓
フォローアップ（未反応者への再送、登録者への商談化アプローチ）
   ↓
クロージング（有料転換 or 商談設定）
```

## 各工程の詳細

### 1. ターゲットリスト作成
- [03_lead_generation.md](03_lead_generation.md) の適法な経路で取得したドメイン・アドレスをリスト化
- 初期フェーズでは1日あたりの送信数を意図的に絞る（人間レビューのキャパシティが上限になる、
  [06_human_review.md](06_human_review.md)）

### 2. AIパイプライン実行
- ドメインを入力し、レポート・営業メールドラフトを生成（[05_ai_pipeline.md](05_ai_pipeline.md)）

### 3. 人間レビュー・承認
- チェックリストに沿ってレビューし、修正・承認・差し戻しを行う

### 4. 送信
- 特定電子メール法に基づく表示義務（送信者情報、オプトアウト方法の明記）を満たした状態で送信

### 5. モニタリング
- 開封・クリック・登録の有無をトラッキングする
- 未反応の場合、一定期間後に別角度のフォローメールを1回のみ送る（過度な追撃はしない）

### 6. フォローアップ
- 登録した企業には、担当者による個別フォロー（電話・メール・オンライン商談の提案）を行う
- ここで初めて「人対人」の営業プロセスへ移行する

### 7. クロージング
- 有料プランへの案内、または商談設定
- 成約有無に関わらず、結果を記録し次のレポート精度改善へフィードバックする（[12_operations.md](12_operations.md)）

## 初期フェーズの運用方針

- 完全に少人数（1〜2名）で回せる規模からスタートする
- 「送信数を増やす」より「1通あたりの反応率を上げる」ことを優先する
- 反応率・登録率のデータが十分に溜まるまでは、送信対象業種を絞り込む
  （[16_validation_plan.md](16_validation_plan.md)）
