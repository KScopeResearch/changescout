# 02_user_journey.md — ユーザージャーニー

## 全体像

```
認知 → 無料レポート閲覧 → 登録 → 継続利用 → 紹介
```

「プロフィール入力」という工程がジャーニーに存在しない点が、従来型（ChangeScout）との最大の違い。

## 1. 認知

エンドターゲット企業の担当者・経営者が、こちらからの接触によって初めてサービスを知る。

- 主経路: 営業メール（1通目がすでにレポート付き）
- 副経路: 紹介、SNS経由の接点、展示会・セミナーでの名刺交換後のフォローメール

この段階でのゴールは「開封」「クリック」ではなく、**「これは自分（自社）向けだ」という一次認知**。
件名・冒頭で会社名・業界固有の変化に触れることで、テンプレート営業メールとの違いを一瞬で伝える。

## 2. 無料レポート閲覧

メール内リンクから、Web上のレポートページ（LP兼レポート）に遷移する。

- 会社名・業種が正しく認識されていることを最初の3秒で示す
- 「なぜこの内容が自社に関係あるか」の根拠（市場変化・法改正・ニュース等）を明示する
- 詳細は [07_free_report.md](07_free_report.md)

閲覧時点ではまだ何も登録させない。読み終えた後に「もっと詳しく見たい」という欲求が
自然に生まれる設計にする（詳細は [10_lp_structure.md](10_lp_structure.md)）。

## 3. 登録

「続きを見る」「詳細レポートを受け取る」ボタンから、メールアドレス（+可能なら部署・役職）を
登録してもらう。この時点ではすでに一度、無料レポートで価値を体験しているため、
従来のコールドリードよりコンバージョン意欲が高い状態のはずである。

- 登録項目は最小限（メールアドレスのみ、または+氏名）
- 登録直後に有料版・詳細版の一部をその場で見せる（フルペイウォールにしない）

## 4. 継続利用

登録後、以下のいずれか、または組み合わせで継続的な関係を作る。

- 定期更新版レポート（月次・四半期）の配信
- 変化があった時のアラート通知
- 有料プラン（詳細版・API連携等）への案内
- 営業担当による商談化（人手のフォロー、[11_sales_process.md](11_sales_process.md)）

## 5. 紹介

満足度の高い顧客から、同業種・取引先への紹介を促す。AORの体験自体が「送っただけで価値が伝わった」
という驚きを伴うため、紹介の口実として語られやすい（"うちにもこんなレポートが届いた"という話題性）。

- 紹介特典（有料プランの割引・詳細レポート追加等）の設計は [09_pricing.md](09_pricing.md) を参照
- 紹介元・紹介先双方の同意を得た上でのみ次のアプローチを行う（[14_risk.md](14_risk.md)）

## ジャーニー上のKPI仮説（検証対象）

| 段階 | 主要指標 | 備考 |
|---|---|---|
| 認知 | 開封率・クリック率 | 通常のコールドメール比較がベースライン |
| 無料レポート | 滞在時間・スクロール完読率 | 「自分向け」と感じたかの代理指標 |
| 登録 | レポート閲覧→登録の転換率 | 最重要指標。ここが低いと無料レポートの精度不足 |
| 継続利用 | 有料転換率・解約率 | [16_validation_plan.md](16_validation_plan.md) で仮説化 |
| 紹介 | 紹介経由リード数 | 中長期指標 |
