# 01_concept.md — サービス概要

## 背景・課題仮説

実ユーザーへのヒアリングで、従来型（ChangeScout型）の

プロフィール入力 → 分析 → レポート

というフローには

**「価値を理解する前に入力を求められる」**

という致命的な離脱ポイントがあることが分かった。入力コストを払う前に「これは自分に関係がある」と
思わせられなければ、そもそも入力画面にすら辿り着かない。

## コンセプト

**価値を先に見せる。**

ユーザー（見込み顧客）が何も入力する前に、こちらが先回りして

「御社向けにレポートを作ってみました」

という状態を作り、それを最初の接点として提示する。プロフィール入力という
ゼロクリックの負担すら発生しない、**ギブファースト型**の営業リードジェネレーションサービス。

## サービス名（仮称）

**AI Opportunity Report（AOR）**

`docs/strategy/PROJECT.md` の Product Portfolio 候補に元々挙がっていた名称を採用。

## USP（Unique Selling Proposition）

1. **プロフィール入力ゼロ**
   会社ドメイン（メールアドレス）さえ分かれば、企業ホームページ・公開情報から自動でレポートを生成する。相手に何も入力させない。
2. **営業の一通目がすでに価値である**
   一般的なコールドメールは「時間をください」で始まるが、AORは「すでに御社向けの分析を終えています」で始まる。受け手にとって最初のメールの時点で読む理由がある。
3. **Human in the Loopによる品質担保**
   完全自動生成ではなく、AIドラフト→人間レビュー→送信、という工程を必須とすることで、誤情報・的外れな内容による信頼毀損リスクを抑える（詳細は [06_human_review.md](06_human_review.md)）。
4. **無料レポートが自然なリードマグネットになる**
   「もっと詳しく見たい」という欲求そのものが登録導線になるため、別途ホワイトペーパー等を用意する必要がない。

## ターゲット（二層構造であることに注意）

AORには「サービスの利用者（顧客）」と「レポートの送付先（エンドターゲット企業）」という
2種類のターゲットが存在する。

### レポート送付先（エンドターゲット企業）

ChangeScoutの候補市場と同じ切り口で検証する。

- 税理士・会計事務所
- 建設業
- 補助金申請が絡む中小企業
- 法改正の影響を受けやすい業種
- バックオフィス業務を抱える中堅・中小企業

### サービスの利用者（顧客）

最初のフェーズでは **AOR自体を自社の営業ツールとして使う（自社が売り手）**。
将来的には以下のような顧客への提供（OEM/エージェンシー展開）も視野に入れる。

- above の業種向けにサービスを売り込みたいSaaS企業
- above の業種を顧客に持つ士業事務所・コンサルティング会社
- 新規開拓に課題を持つB2B営業代行会社

初期フェーズでは「顧客 = 自社」とし、自社の他プロダクト（将来のChangeScout SaaS化含む）の
リードジェネエンジンとして使う方が検証コストが低い（詳細は [16_validation_plan.md](16_validation_plan.md)）。

## 既存ChangeScoutとの違い

| 観点 | ChangeScout | AI Opportunity Report |
|---|---|---|
| フロー起点 | ユーザーが能動的にアクセスし入力する（プル型） | こちらが先に分析を終え、送りつける（プッシュ型） |
| 最初の情報入力 | プロフィール入力が必須 | 入力不要（相手のメールドメインだけで開始） |
| 価値提示のタイミング | 入力完了後 | 接触の瞬間（1通目のメール） |
| 主な役割 | 継続利用されるプロダクト本体（SaaS） | 新規顧客を獲得するための「営業エンジン」 |
| ゴール | 継続的な市場変化レポートの購読 | 「これは自分向けだ」と思わせ、登録・商談へつなげる |
| 自動化方針 | プロダクトとして高い自動化を目指す | 最初は意図的にHuman in the Loopを残す |

両者は競合ではなく補完関係にある。AORが生み出した「登録」「関心を持った企業」を
ChangeScout（または将来のSaaS群）へ引き継ぐ、**リードジェネ層とプロダクト層の分業**という位置づけ。
詳細は [16_validation_plan.md](16_validation_plan.md) の「既存ChangeScoutとの役割分担」を参照。

## なぜ今か

AI SDR / AI Prospecting市場は急拡大しており、市場規模は2025年の41.2億ドルから2030年に
150.1億ドルへ、年平均成長率29.5%で成長すると見込まれている。VCはここ2年でAI SDRスタートアップに
4億ドル以上を投資している。一方で「完全自動のAI SDR」は誤送信・ブランド毀損のリスクが
指摘され始めており（[14_risk.md](14_risk.md)）、"人間の関与を残したまま質を担保する"モデルには
まだ十分な差別化余地がある。
