# Mission

AIを活用し、企業や個人が「情報収集・分析・意思決定」に費やす時間を大幅に削減する。

私たちは単なるAIツールを作るのではなく、
「変化を価値へ変える」サービスを継続的に生み出す。

一人でも複数のAIと協働することで、
少人数でも継続的に新しいサービスを生み出せる仕組みを構築する。

# First Priority

最初のプロダクトを作ることではない。

最初の顧客を見つけることである。

# Decision Rule

新しいアイデアは、以下の条件を満たすものだけ採用する。

- 顧客が明確である
- 最初の100社へ自力でアプローチできる
- 30〜50時間でMVPを作れる
- 月額課金モデルにできる
- 他のプロダクトでも再利用できる資産が増える

この条件を満たさないものは採用しない。
