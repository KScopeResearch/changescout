＃VALIDATION_CRITERIA.md

Phase 3（MVP Validation）準備。`docs/validation/USER_INTERVIEW_GUIDE.md`で得た反応を、`docs/strategy/ROADMAP.md`の「Phase 3移行条件」の充足判定に使えるよう評価軸として整理する。

## 評価の考え方

- 各軸は5段階（1〜5）と自由記述コメントの組で記録する。数値だけで判断せず、必ずコメントを添える。
- 「良い反応だった」という総合印象ではなく、軸ごとに分けて記録すること。1つの軸で高評価・別の軸で低評価、という結果自体が重要な情報になる。
- 社交辞令的な高評価（「いいですね」とだけ言われた場合）は、具体的な理由を伴わない限りスコアを高くつけない。

## 評価軸

### 1. 市場変化情報は営業機会として理解できるか
- 5: 説明なしで「なぜ自社に関係するか」を自分の言葉で言い直せた
- 3: 断片的には理解したが、関連性の説明を求められた
- 1: 何が起きているか・なぜ自社に関係するかを説明できなかった

### 2. 判断理由は納得できるか
- 5: 根拠に具体的な反論・追加質問なく同意した
- 3: 一部は納得したが、「なぜそう言えるのか」の追加説明を求めた
- 1: 「それらしいことを言っているだけ」という反応、または明確な違和感の指摘があった

### 3. 推奨アクションは実行可能と思えるか
- 5: 「これなら明日からできる」等、実行イメージを具体的に語った
- 3: 方向性は理解したが、実行する上での不足（誰が・いつ・何を使って等）を指摘した
- 1: 何をすればいいか分からない、または現実的でないと明言した

### 4. AI推定表現への違和感はないか
- 5: 「推定値」「想定」「可能性」という表現を自然に受け止め、確定情報と誤解しなかった
- 3: 表現自体は理解したが、もっと明確な根拠の提示を求めた
- 1: 「結局どこまで信用していいか分からない」等、不信感の表明があった

### 5. 継続利用意向
- 5: 「定期的に見たい」等、自発的な継続利用の意思表示があった
- 3: 「内容次第では」「〇〇が改善されれば」等、条件付きの反応
- 1: 明確に「今のままでは不要」という反応

## Phase 3移行条件との対応

- 評価軸2・3で具体的なコメント（賞賛のみでなく指摘を含む）が1件以上得られた場合、`docs/strategy/ROADMAP.md`のPhase 3移行条件2（判断理由・推奨アクションへの外部評価）を満たしたとみなす。
- 評価軸1・4・5は、条件2そのものではないが、Phase 3で実際にAI生成へ投資すべきかどうかの判断材料として`docs/strategy/ROADMAP.md`のRemaining Issues（初期ユーザー検証）に反映する。
- 個々のヒアリング結果は`docs/validation/FEEDBACK_TEMPLATE.md`で記録し、本ファイルの評価軸に沿って集計する。
