＃USER_INTERVIEW_GUIDE.md

Phase 3（MVP Validation）準備。`docs/strategy/ROADMAP.md`の「Phase 3移行条件」1・2（実企業へのデモとフィードバック取得、判断理由・推奨アクションへの外部評価）を満たすためのヒアリング指針。

## 想定ユーザー

- `docs/strategy/PROJECT.md`のターゲット市場のうち、2026-07-28時点でDashboard/Opportunity Detail/AI Action Planがすべて連携済みの8業種（製造業・建設業・士業・IT・DX支援・EC事業者・フリーランス開発者・経営コンサルタント・その他）に該当する中小企業の経営者・経営企画・新規事業担当者を優先する。
- 「その他」を含む全業種でCard1〜3・AI Action Plan #1〜3が業種専用コンテンツで揃っているため、以前のように「その他」の優先度を下げる必要はない。
- 既存顧客・取引先など、ChangeScoutというサービス名を初めて聞く相手を基本とする（社内関係者など前提知識がある相手は、理解度検証としてのバイアスがかかるため補助的な位置づけにとどめる）。

## ヒアリング目的

これは購入意向調査ではなく、**体験価値の検証**である。目的は以下の4点に限定する。

1. 市場変化→営業機会という情報の流れが、初見のユーザーに理解できるか
2. 判断理由・推奨アクションに納得感があるか（＝AIが「それらしいことを言っているだけ」に見えていないか）
3. 「AI推定値」「AI Action Plan」等の表現に違和感や不信感が出ないか
4. もう一度使いたい／情報が来たら見たいと思えるか（継続利用意向）

価格・契約条件・導入時期についての深掘りは今回のスコープ外とする（Phase 3移行条件のうち、これらはまだ判断材料が揃っていないため）。

## 質問項目

`docs/validation/DEMO_SCENARIO.md`のデモを見せたあとに、以下の順で聞く。すべてオープンクエスチョンとし、はい/いいえで終わらせない。

**導入（デモ前）**
- 現在、御社に関係しそうな制度変化や市場動向は、どうやって情報収集していますか
- その情報収集で、困っていること・手間だと感じることはありますか

**理解度確認（デモ直後）**
- 今見た画面で、何が起きていて、なぜそれが御社に関係すると言われたか、ご自身の言葉で説明していただけますか
- Opportunity Score（機会スコア）や「影響候補企業18社」といった数字は、何を根拠にした数字だと感じましたか

**判断理由・推奨アクションへの納得感**
- 「判断理由」に書かれていた内容は、納得できるものでしたか。違和感があった部分があれば教えてください
- 「推奨アクション」は、実際に御社の営業担当者が明日から実行できそうな内容でしたか。何が足りないと感じましたか

**AI推定表現への反応**
- 「AI推定値」「想定」「可能性があります」といった表現を見て、どう感じましたか（信頼できる／曖昧すぎる／ちょうど良い、など）
- もしこれが「確実に受注できます」のような言い切り表現だったら、印象は変わりますか

**継続利用意向**
- こういう情報が定期的に届くとしたら、見たいと思いますか。それはなぜですか
- 今の内容で足りないと感じる情報や機能は何ですか

## 聞いてはいけない誘導質問

以下のような、回答を特定方向へ誘導する聞き方はしない。

- 「良いサービスだと思いませんか？」のようなYes誘導
- 「AIがここまでできるのはすごいと思いませんか？」のような機能自慢を前提にした質問
- 「いくらなら払いますか？」のような、時期尚早な価格コミットを迫る質問（Phase 3移行条件がまだ価格検証を求めていない段階のため）。価格・支払意思（WTP）のヒアリングは、この価値検証で理解度・信頼度・継続利用意向の基準を満たした企業に対してのみ、別途Phase 3.5として`docs/strategy/sales/05_hearing_sheet.md`セクション6で実施する（2026-07-28、`docs/strategy/consistency_review.md` M1を受けて明確化）
- 「導入するとしたらいつ頃ですか？」のような、購入意向を前提とした質問
- こちらから先に「〇〇な点が良いと思うのですが、どうですか？」と評価ポイントを先出しする質問

## 判断ポイント

- ヒアリング中に「判断理由」「推奨アクション」について**具体的な指摘**（褒め言葉ではなく、違和感・矛盾・不足の指摘）が出た場合、それは`docs/strategy/ROADMAP.md`のPhase 3移行条件2（外部評価）を満たす有効な材料として記録する。社交辞令的な「良いですね」のみの反応は、条件2の充足としてはカウントしない。
- 詳細な評価軸・合格基準は`docs/validation/VALIDATION_CRITERIA.md`を参照。ヒアリング結果は`docs/validation/FEEDBACK_TEMPLATE.md`に記録する。
